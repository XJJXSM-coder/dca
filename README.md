# 定投记录（dca-tracker）

## 装到安卓手机

**必须 HTTPS** —— 安卓 Chrome 只允许在安全上下文里安装 PWA。
`http://192.168.1.156:5202` 这种内网 HTTP 只能"添加到主屏幕"（带地址栏的快捷方式）。

最省事的路：把 `dist/` 上传到 GitHub Pages 或 Vercel，得到 https 地址后在手机 Chrome 里
`⋮ → 安装应用`。

详见 [安卓安装指南](../docs/安卓安装指南.md)。

一个**本地离线**的定投记录 PWA。不联网、不登录、不上传，数据只存在你自己的浏览器里。

## 这是什么

不是记账软件，是**纪律执行器**。

它解决的不是「钱花哪了」——那件事已经被 6,500 元的预算表解决了。
它解决的是执行时会动摇：

- 跌了想加仓
- 涨了想多投
- 手头紧想挪用
- 忘了投
- 记不清成本价

## 三条设计铁律

1. **能自动算的，绝不让你填** —— 成本价、覆盖率、剩余额度、连续月数全部自动
2. **该拦的拦住，不只是提醒** —— 超额度时按钮直接变灰，不是弹个提示
3. **只记事实，不记情绪** —— 没有「心情」「看涨看跌」这类字段

## 明确不做

| 不做 | 原因 |
|---|---|
| 实时行情推送 | 会让你每天看十次账户，摧毁「不看盘」这条纪律 |
| 涨跌红绿闪烁 | 制造情绪波动，而你要的是「买了就不看」 |
| 一键加仓按钮 | 这是把冲动做成按钮 |
| 推送「今天跌了 3%」 | 每天提醒你一次「要不要做点什么」 |
| 云同步 / 登录 | 本地够用，多一层服务多一层风险 |
| 社交 / 排行榜 | 和「默默存 30 年」无关 |
| AI 建议 / 智能调仓 | 方案已定死，任何「建议」都在动摇你 |

## URL 直达

## 五个页面

| 页面 | 干什么 |
|---|---|
| **任务** | 本月还剩几件事没做（第一屏是它，不是余额） |
| **持仓** | 录入交易，自动算成本价与浮盈亏 |
| **现金** | 三个账户余额 + 三档阈值判断 |
| **更多** | 按月回溯历史 |
| **设置** | 改参数、导出备份、开启持久化存储 |

## 三档阈值

现金水位分三段，不是一条线：

| 档位 | 金额 | 覆盖月数 | App 行为 |
|---|---:|---:|---|
| 停投线 | 10,500 | 3.3 | 按钮变灰，禁止新增 |
| 警戒线 | 15,000 | 4.8 | 黄灯提示，额度继续 |
| 目标线 | 18,900 | 6.0 | 绿灯，正常 |

> **为什么不是一条线**：原先规则是「现金 < 15,000 停投」，但计划里 11 月末现金只有 14,288。
> 严格执行这条会让 11 月投不出去，进而 3 月到不了 19,188——规则和计划自相矛盾。
> 拆成三档后，14,288 是「黄灯但可投」，逻辑自洽。

## 任务会自己消失

执行清单不是固定 5 条，而是**按当月实际情况生成**：

| 任务 | 什么时候出现 |
|---|---|
| 划 500 元买 VGT | 每月 22 号（20 号发薪 + 2 天） |
| 结余转余利宝 | 每月 22 号 |
| **清空月利宝** | **只在月利宝里还有钱时出现**；清零后永久消失 |
| 记录当月汇率 | 每月 25 号 |
| 月末对账 | 每月 30 号 |
| 特殊事项 | 仅 2027-02 / 2027-03 |

**「清空月利宝」是最典型的例子**：这个月转出去了，下个月这条就不再出现。
不会在你已经做完之后还天天提醒。

## 额度只提示，不拦截

每月预算是 500 元，但 App **不会因为你超了就锁住按钮**。

原因：补投、追加、记错重录都会让某个月超过 500。锁住只会逼你去改数据，
不如照实记录，然后在首页用黄字告诉你「超预算 200 元」。

**规则是给判断用的，不是给按钮用的。**

## 关键计算

```
成本价   = Σ USDC / Σ 股数        （不是人民币 ÷ 股数，否则汇率混进成本）
实际汇率 = Σ 人民币 / Σ USDC
覆盖率   = 总现金 / 刚性支出 3,150
剩余额度 = 500 − 本月已投   （可为负，仅提示）
```

## 开发

```bash
# 环境（node 不在 PATH 上，用 DSH 内置）
export PATH="/c/Users/Administrator/.dsh/dsh-runtimes/dsh-primary-runtime/dependencies/node:/c/Users/Administrator/.dsh/dsh-runtimes/dsh-primary-runtime/dependencies/node/bin:$PATH"

node pnpm-run.mjs install     # 装依赖
node pnpm-run.mjs exec vite   # 开发服务器
node pnpm-run.mjs exec vitest run   # 跑测试
node pnpm-run.mjs exec vite build   # 生产构建
node scripts/verify.mjs       # 完整验收
```

> pnpm 会打印 `[ERR_PNPM_IGNORED_BUILDS] Ignored build scripts: esbuild` 和
> `[WARN] The install that runs before scripts failed`。
> **这是噪音，忽略它**——vite 用的是预编译的 esbuild 二进制，构建照常工作。

## 装到手机上

1. 构建：`node pnpm-run.mjs exec vite build`
2. 把 `dist/` 整个目录传到任意静态托管（GitHub Pages / Vercel / 自己的服务器）
3. 手机浏览器打开网址 → 菜单里选「添加到主屏幕」
4. 之后从桌面图标打开，是全屏的、能离线用的

**首次打开后一定要去「设置」点一次「开启持久化存储」**——
否则浏览器在存储紧张时可能回收你的数据。

## 改额度月份

补投、追加这类情况，钱是这个月付的，但额度算上个月。处理方式：

持仓页 → 交易记录 → 点「**改月份**」→ 选月份 → 保存

留空则按成交月份算。记录下方会显示「算作 2026-10 的额度」。

## 实时行情

持仓页的现价**自动跟随实时行情**，每 60 秒刷新一次。

数据来源：东方财富公开接口（`push2.eastmoney.com`），带 `Access-Control-Allow-Origin: *`，
浏览器可直连，**不需要 API Key、不需要后端、不产生费用**。

| 行为 | 说明 |
|---|---|
| 打开持仓页 | 立即拉一次 |
| 停留在页面上 | 每 60 秒自动刷新 |
| 切回 App | 立刻刷新（不等 60 秒） |
| 切到其他页 | 停止轮询，省流量省电 |
| 手动改现价 | **自动关闭跟随**，显示「已手动覆盖」 |
| 点「恢复跟随」 | 重新跟随行情 |

行情栏显示：最新价、涨跌额、涨跌幅、上次成功时间。
网络失败不弹错，静默重试。

### 为什么是 60 秒

美股不是 7×24 交易，日内价格变化以分钟计。
**再快没有意义，还费电。**

### 手动价 vs 行情价

改了现价想保存？点「**保存现价到本月**」写入数据库，作为该月的月末参照。
这样即使行情接口哪天挂了，你也有历史价格可看。

## 删除有二次确认

点「删除」会弹出确认层，显示日期、金额、股数。确认后才真删。
**误触不会丢数据。**

## 备份

数据只在本地，所以**必须定期导出**：

设置 → 导出 JSON → 存到网盘或发给自己

建议每月月末对账时顺手导一次。

## 技术栈

Vite 5 + React 18 + TypeScript 5 + Dexie（IndexedDB）+ vite-plugin-pwa

无后端、无第三方 UI 库、无状态管理库。
